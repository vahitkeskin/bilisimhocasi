## 🔌 Detaylı Port Bağlantı Tablosu (Pinout)

| Arduino Pini | Bileşen Bacağı | Görev / Açıklama |
|:---|:---|:---|
| **`Pin 8`** | 220Ω -> LED Anot (+) | Dijital Çıkış (5V/0V Sinyali) |
| **`GND`** | LED Katot (-) | Toprak Hattı (Devre Tamamlama) |
